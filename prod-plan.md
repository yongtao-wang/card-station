# Product Requirement

This website is a collection of mini games. It provides a platform with multiple mini games of "Flip Card" theme for users to choose.

The website layout is similar to wordle.io, with header and footer. The main body is the gaming area. below game area is a recommendation section for similar games.

Build the website with next.js for SEO optimization.

The website should provide an easy way to manage mini games. For now, each game should be placed in its own directory, and use typescript or javascript to write the functionality. Each mini game is like a component that can be displayed on the page. Each game should maintain its own game history. For now let's use localStorage or cookie to store them.

The website should have a friendly UI, more cartoon-ish with vivid color.

The first game is a standard flip card game.
